# SENTIVRA Capability Matrix

Last verified: **2026-10-12**, against commit `8a4755cc` (branch `audit/ml-hardening-sentivra`), by code inspection and by running the backend test suite (`242 passed, 1 skipped` — the skip is a POSIX-permission test that cannot run on Windows). Every row below was checked against the source file or test named in it; nothing is listed on the strength of a README claim.

**How to read the statuses**

| Status | Meaning |
|---|---|
| **Stable** | Implemented and covered by automated tests; behaves as documented |
| **Experimental** | Implemented and tested, but detection quality is bounded/heuristic or evaluated only on synthetic/simulated data — not validated on real-world traffic |
| **Unconfigured** | Implemented and tested, but needs credentials/paths/a daemon before it can operate |
| **Not implemented** | Designed or documented only; no code path exists |

**Telemetry** is labelled separately: `LIVE` (real input through the API), `DEMO_DATA` (bundled synthetic samples), `SIMULATED` (generated endpoint fleet), `ABSENT` (nothing is feeding it on this install).

## Notes that the table cannot hold

1. **Detector ≠ model.** Every detector above is registered and runs; several (SQLi, prompt, URL, malware-static) run on rule/heuristic layers because their optional ML artifacts are **untrained**. `GET /api/v1/models` reports `trained: false` with a reason for exactly those, and the dashboard's Models page shows the same.
2. **Synthetic ≠ real.** The network models' and fleet baseline's metrics were measured on synthetic/simulated data with strict train/threshold/test separation. They prove the pipeline and calibration work; they are **not** evidence of performance on real traffic, and this repository publishes no such claim.
3. **A missing engine is never a clean scan.** Unreachable ClamAV, untrained models and unconfigured connectors surface as `Not Configured`/`PARTIAL`/503 states (regression-tested in `test_failure_semantics.py` and `test_webhooks.py`), never as SAFE.
4. **Verification machine state** (2026-10-12, Windows 11): `clamd`, `suricata` and `zeek` binaries absent; no osquery agent; no Gmail/Telegram/WhatsApp credentials; SQLite dev database with demo/audit traffic only.
