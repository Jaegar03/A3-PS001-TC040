# Scientific Validation Report

Existing regression tests cover file/YARA, SQL, prompt, URL, network,
endpoint/log/Sigma, webhook and risk-engine paths. Earlier reports under
`research/evaluation/` are preliminary local or synthetic evidence, not
deployment claims.

The evidence is limited by attack-list SQL data, small prompt data, homepage-
heavy URL data, synthetic network models and simulated endpoint data. No full
public network benchmark, live telemetry validation, or live provider exercise
was run. No metric is reported for those items.
