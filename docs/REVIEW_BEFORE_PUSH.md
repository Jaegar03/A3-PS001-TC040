## Owner decision / push commands

The owner must review `docs/OPEN_QUESTIONS.md`, inspect the diff, and decide
whether to push. This branch does not run the push. If approved, the owner can
restore the desired push URL and push the branch using their own reviewed
commands, for example:

```powershell

git checkout audit/ml-hardening
git push -u origin audit/ml-hardening
```

Do not push the ignored raw datasets, `.env`, `.sentivra/`, or local virtual
environments.
